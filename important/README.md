## Voice + Girl Avatar
The portfolio now includes a generated illustrated girl avatar and a browser-based voice assistant.
- Click **Speak to me** for spoken responses.
- Double-click **Speak to me** in Chrome/Edge to use microphone input if permission is granted.
- Voice uses the browser's built-in Speech Synthesis API, so no API key is required.
